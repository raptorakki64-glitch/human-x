# HUMAN X — A Life Level-Up Center

Founder personal-brand site for Golla Aakash Venkat ("Akki").

Where **Schooling, Nutrition, Farming, and AI** unite to elevate human potential.

> Learn Better. Eat Better. Grow Better. Live Better.

## Structure

- `index.html` — the entire site: one self-contained file (HTML + CSS + vanilla JS, no build step)
- `assets/` — images (opening poster, hero, section photos)

## Run locally

Open `index.html` in a browser, or:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## Waitlist

The hero email form delivers signups via [FormSubmit](https://formsubmit.co) — no backend required.
